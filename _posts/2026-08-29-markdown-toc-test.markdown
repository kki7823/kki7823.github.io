이 글은 목차와 마크다운 렌더링을 확인하기 위한 테스트 데이터입니다. `h2`, `h3`, `h4` 단계의 제목을 포함하고, 표와 체크리스트, 번호 목록, 링크, 코드 블록을 함께 배치했습니다.

## 1. 시작하기

블로그 글의 목차는 보통 두 번째 단계 제목부터 생성됩니다. 아래 구조를 통해 테마가 어떤 깊이까지 목차에 포함하는지 확인할 수 있습니다.

### 1.1 테스트 목적

이 문서는 다음 항목을 확인합니다.

- 목차에 표시되는 제목 단계
- 긴 제목이 줄바꿈될 때의 스타일
- 본문 요소 사이의 간격
- 코드와 표의 렌더링 방식

### 1.2 기대하는 확인 포인트

목차가 있다면 현재 섹션 제목이 잘 표시되는지, 제목의 순서가 자연스럽게 이어지는지 확인합니다. 목차가 없다면 본문 헤딩 스타일만 확인해도 충분합니다.

#### 1.2.1 네 번째 단계 제목

네 번째 단계 제목은 목차에 포함될 수도 있고 제외될 수도 있습니다. 테마 설정에 따라 다르므로 실제 화면에서 깊이를 확인하기 위한 샘플입니다.

## 2. 마크다운 요소

아래에는 자주 쓰는 마크다운 문법을 모았습니다.

### 2.1 강조와 링크

본문 안에서 **굵은 글씨**, *기울임 글씨*, `짧은 코드`, [Jekyll 공식 문서](https://jekyllrb.com/docs/) 링크가 어떻게 보이는지 확인합니다.

### 2.2 번호 목록

1. 저장소에 글 파일을 추가합니다.
2. 로컬 서버를 실행합니다.
3. 목록과 제목이 의도대로 보이는지 확인합니다.
4. 필요하면 테마 스타일을 조정합니다.

### 2.3 체크리스트

- [x] 한글 제목 확인
- [x] 목차용 헤딩 확인
- [ ] 실제 포스트 작성 전에 최종 스타일 확인

## 3. 표 테스트

표는 정렬, 테두리, 모바일 표시 방식을 확인하기 좋습니다.

| 항목 | 설명 | 상태 |
| --- | --- | --- |
| 제목 | 글 상단의 제목 크기 확인 | 완료 |
| 목차 | 헤딩 계층 표시 확인 | 진행 중 |
| 코드 | 코드 블록 가독성 확인 | 대기 |

## 4. 코드 예시

아래 코드는 짧은 Go 예시입니다.

```go
type Post struct {
	Title string
	Slug  string
	Tags  []string
}

func NewPost(title string, tags []string) Post {
	return Post{
		Title: title,
		Slug:  "sample-post",
		Tags:  tags,
	}
}
```

## 5. 긴 제목 테스트: 목차 영역에서 제목이 길어질 때 줄바꿈과 간격이 자연스러운지 확인하기

긴 제목은 목차와 본문 양쪽에서 문제를 만들 수 있습니다. 특히 작은 화면에서는 한 줄에 담기지 않기 때문에 줄바꿈 위치와 행간을 확인해야 합니다.

### 5.1 하위 제목도 조금 길게 작성해서 목차의 들여쓰기와 줄바꿈 상태를 확인하기

이 섹션은 하위 제목이 길 때 목차가 지나치게 좁아지거나 본문과 겹치지 않는지 확인하기 위한 데이터입니다.

## 6. 마무리

이 샘플 포스트를 통해 블로그 테마의 기본 읽기 경험과 목차 표시 방식을 빠르게 확인할 수 있습니다. 실제 글을 쓰기 전에 폰트 크기, 제목 간격, 코드 블록 색상, 표의 모바일 대응을 살펴보면 좋습니다.
