이 글은 블로그 테마의 기본 본문 스타일을 확인하기 위한 샘플 포스트입니다. 문단 간격, 한글 줄바꿈, 링크 색상, 인용문, 목록, 이미지가 없는 상태의 여백을 확인할 수 있도록 평범한 일상 기록처럼 구성했습니다.

## 오늘의 생각

새 블로그를 만들 때 가장 먼저 보고 싶은 것은 화려한 기능보다 글이 편하게 읽히는지입니다. 제목이 너무 크지 않은지, 본문 행간이 답답하지 않은지, 모바일에서도 문장이 자연스럽게 떨어지는지 확인하는 일이 중요합니다.

블로그는 결국 오래 읽고 오래 쓰는 공간이라서, 첫 화면보다 글 한 편의 호흡이 더 중요할 때가 많습니다. 그래서 이 문단은 일부러 조금 길게 작성했습니다. 한글 문장이 여러 줄로 이어질 때 폭과 줄 간격이 어떻게 보이는지 확인하기 좋습니다.

## 샘플 목록

- 첫 번째 항목은 짧은 문장입니다.
- 두 번째 항목은 조금 더 긴 문장입니다. 목록 항목이 여러 줄로 넘어갈 때 들여쓰기와 줄 간격이 어색하지 않은지 확인합니다.
- 세 번째 항목은 강조 표현을 포함합니다. **중요한 부분**과 `inline code`가 본문 안에서 잘 구분되는지 봅니다.

인용문 아래에 다시 일반 문단이 이어질 때 간격이 자연스러운지도 함께 확인합니다.

## 코드 블록 테스트

```go
package main

import "fmt"

func main() {
	fmt.Println("안녕하세요, 블로그!")
}
```

코드 블록은 개발 블로그에서 자주 등장합니다. 배경색, 글꼴 크기, 좌우 여백, 모바일 가로 스크롤 여부를 확인하기에 좋습니다.

## 마무리

이 포스트는 실제 내용보다는 테마 확인을 목적으로 합니다. 제목, 문단, 목록, 인용문, 코드 블록이 함께 있을 때 전체적인 균형이 자연스러운지 살펴보면 됩니다.
